# 2028 대입 개요

2028학년도는 **2022 개정 교육과정**과 2023년 12월에 확정된 **2028 대입제도 개편안**이 처음 적용되는 입시입니다.
2025년에 고1이 된 학생들이 첫 적용 대상입니다.

## 주요 변화

| 구분 | 변화 내용 |
|---|---|
| 수능 | 국어·수학·사회·과학 탐구의 **선택과목 폐지**, 모든 수험생이 같은 시험을 치르는 통합형 체제 |
| 수능 탐구 | 사회·과학탐구 응시자는 **통합사회와 통합과학을 모두** 응시 |
| 수능 형식 | 논·서술형 문항은 도입하지 않음, 미적분Ⅱ·기하 등 '심화수학' 영역은 수능에 포함하지 않음 |
| 내신 | 석차등급 9등급제에서 **5등급제**로 변경, 성취평가(A~E)와 함께 기재 |
| 8월 모의평가 | 8월 말 실시 후 성적을 확인하고 수시 원서접수가 시작되는 일정 |

## 내신(학생부 교과) 변화

- 2025학년도 고등학교 입학생부터 석차등급이 5등급제로 바뀌었고, 1등급 비율이 상위 누적 4%에서 10%로 넓어졌습니다.
- 성적표에는 A~E 성취평가와 석차등급이 함께 기재됩니다.
- 융합선택과목 중 사회·과학 교과 9과목은 상대평가 없이 **성취도(절대평가)만** 기재됩니다.

## 2028학년도 대학입학전형기본사항 주요 변경 (2025.8 발표)

대교협이 확정한 기본사항의 주요 변경은 아래 세 가지입니다. 이후 2026년 7월에 개정본이 공개되었으니 원문에서 확인하세요.

1. **특성화고졸업자 특별전형**: 동일계열 인정 기준을 '기준학과'에서 **교과(군)** 기준으로 바꾸고, 학생이 24학점 이상 이수한 교과(군)을 동일계열로 인정합니다.
2. **농어촌학생 특별전형**: 지원자격 확인서 등을 대교협 **공통양식**으로 통일합니다.
3. **농어촌·지역인재·특성화고졸업자 특별전형**: 지원자격의 학교 '졸업일'은 학교생활기록부에 기재된 날짜를 기준으로 합니다.

## 모집 동향 (2028학년도 대학입학전형시행계획, 2026.4.29 기준)

- 전국 194개 회원대학이 제출한 시행계획을 대교협이 취합해 공표했습니다.
- 전체 모집인원과 수시 모집인원은 늘고 정시 모집인원은 줄었습니다.
- 수시는 학생부위주, 정시는 수능위주로 선발하는 기조가 유지되었습니다.
- 자세한 수치는 [수시](susi.md), [정시](jeongsi.md) 페이지를 참고하세요.
