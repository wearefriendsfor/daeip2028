# 학년별 준비

> 2028학년도 입시생은 2025년에 고1이 된 학생들입니다. 2026년 11월 현재 **고2**이며, 2027년에 고3이 됩니다.
> 아래는 공식 일정과 제도 변화를 바탕으로 정리한 일반적인 점검 항목입니다.

## 현재 고2 (2026년)

- 내신 5등급제와 성취평가 병기 방식을 이해하고, 학교 성적표의 표기를 확인합니다.
- 통합사회·통합과학, 국어·수학 공통 범위를 점검합니다. 선택과목이 없으므로 같은 범위를 모두가 공부합니다.
- 진로에 맞는 과목 이수 현황을 정리하고, 지원 희망 대학의 요구 사항을 확인합니다.
- 희망 대학 입학처의 **2028학년도 시행계획**과 모집요강 예고 자료를 살펴봅니다.

## 고3 (2027년)

| 시기 | 점검 항목 |
|---|---|
| 3월 | 한국교육과정평가원이 공고하는 수능 시행 기본계획 확인 |
| 6월 | 6월 모의평가로 학습 상황 점검 |
| 8월 말 | 8월 모의평가 성적을 확인하고 수시 지원 전략 정리 |
| 9월 20~23일 | 수시 원서접수 (대학별 3일 이상) |
| 11월 18일 | 수능 응시 |
| 12월 10일 | 수능 성적 통지, 정시 지원 전략 수립 |
| 12월 21일까지 | 수시 합격자 발표 |
| 2028년 1월 3~6일 | 정시 원서접수 |

## 학부모·교사를 위한 점검

- 자녀·학생이 지원할 대학의 모집요강을 함께 확인합니다.
- 일정은 [전형 일정](schedule.md) 표를 기준으로 하고, 대학별 공고로 다시 확인합니다.
- 제도 변화나 개정은 [공식 자료 링크](links.md)에서 확인합니다.
